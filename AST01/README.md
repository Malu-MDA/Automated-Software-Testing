# AST01 - Carrinho de Compras de um E-commerce

## Objetivo

Projetar casos de teste para validar o cálculo de frete e a aplicação de cupons de desconto em um carrinho de compras de um e-commerce.

## Técnicas utilizadas

- Classes de Equivalência
- Análise de Valores Limite

## Entrega

A atividade foi desenvolvida com base nas regras de negócio propostas e contém os casos de teste para os diferentes cenários.
